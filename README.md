# QR Scanner

A fast, responsive, and privacy-focused QR code and barcode scanner built with **HTML, CSS, and vanilla JavaScript**. Scan codes using your camera, upload images, drag and drop multiple files, and export results without creating an account.

## Features

- **Live Camera Scanning** - Scan QR codes and supported barcodes using your device camera.
- **Image Upload** - Scan codes from images stored on your device.
- **Drag and Drop** - Drop multiple image files into the application.
- **Batch Scanning** - Process multiple images and collect results in one place.
- **Instant Results** - View decoded text, links, and other available code data.
- **Copy Results** - Copy individual scan results to your clipboard.
- **Open Links** - Open detected URLs directly in your browser.
- **Export Results** - Download individual results as TXT and export multiple results as TXT or CSV.
- **Responsive Design** - Works across mobile phones, tablets, laptops, and desktop computers.
- **Privacy-Focused** - Designed to process scans locally in your browser without requiring an account or backend.
- **Lightweight** - Built with HTML, CSS, and vanilla JavaScript, without PHP or frontend frameworks.

## Technologies Used

- **HTML5** - Application structure.
- **CSS3** - Styling, layouts, and responsive design.
- **JavaScript** - Scanning interactions and application logic.
- **Browser APIs** - Camera access, file handling, clipboard access, and downloads.
- **QR/barcode decoding library** - Used if included in the project to decode supported formats.

## Privacy

QR Scanner is designed to keep scanning simple and private.

- No account registration is required.
- No application backend or database is required.
- Images should be processed locally in the browser.
- Camera access requires your permission.
- Scan results are not automatically uploaded to a server by the intended design.

**Important:** Privacy depends on the actual implementation and any third-party libraries or external services used. Review the source code before making privacy guarantees.
